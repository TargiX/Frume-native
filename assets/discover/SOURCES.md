# Discovery puzzle artwork

`coastal-morning.png` is an AI-generated photographic artwork created for Frume on 2026-09-05 with the built-in image generation tool. It depicts an imaginary Mediterranean garden and cove. No external photograph or reference image was used. It is bundled for offline play and is not an Unsplash API result.

The free sample is restricted to this image with the Organic 4x4 cut. It does not grant Premium Cuts access. The app identifies the image as a Frume study rather than attributing it to a photographer.
